# AgendIAgora

Sistema de agenda, caixa, comandas, estoque, financeiro e comissões para
negócios que atendem cliente com hora marcada — salões, petshops,
barbearias, restaurantes, bares, clínicas e outros. **Gratuito, sem
mensalidade, sem limite de tempo de uso.**

Este repositório existe só para distribuir o instalador Windows
compilado. O código-fonte é privado e mantido em outro repositório.

## Baixar

**[Baixar o instalador (Windows)](https://github.com/pmenotti/agendiagora-releases/releases/latest/download/AgendIAgora-Instalador.exe)**
— sempre a versão mais recente.

Veja o [histórico de versões](https://github.com/pmenotti/agendiagora-releases/releases)
para as notas de cada release.

## O que o sistema faz

- **Cadastros** — clientes, profissionais, serviços, produtos e fornecedores
- **Agenda** — marcar, remarcar e ver os horários de cada profissional no dia
- **Caixa** — abrir, fechar, sangrias, reforços e conferência de saldo
- **Comandas (Vendas)** — registrar o que o cliente consumiu e fechar a conta
- **Estoque** — saldo de produtos e histórico completo de movimentações
- **Financeiro** — contas a pagar, a receber, créditos, cheques e cartões
- **Salários e Comissões** — comissão por profissional, personalizável por serviço
- **Relatórios** — aniversariantes, clientes inativos, vendas, lucro e mais
- **Google Agenda** — sincroniza os horários com o Google Agenda
- **Acesso pela Web** — profissional acompanha a própria agenda pelo
  celular, e cliente pode pedir horário pela internet, sem precisar ligar
- **Sistema** — preferências, backup do banco de dados
- **Assistente de IA** — ajuda dentro do próprio sistema, sem acessar
  dados reais de clientes ou vendas

## Segmentos de negócio atendidos

Salão de Beleza, Barbearia, Petshop, Clínica (Estética / Odonto / Fisio),
Spa / Massoterapia, Estúdio de Tatuagem / Piercing, Personal Trainer /
Aula Particular, Estúdio Fotográfico, Lava-jato, Estacionamento, Locação
de Espaços, Oficina Mecânica / Assistência Técnica, Bar / Pub,
Restaurante.

O menu **Sistema → Segmento do Negócio** troca o vocabulário das telas
automaticamente para o segmento escolhido, sem precisar reinstalar nada.

## Já usa outro sistema? Dá pra trazer seus dados

Pagando mensalidade em outro sistema e pensando em trocar pra reduzir
custo? Você não precisa recomeçar do zero. Já é possível trazer os
dados de quem usava o **BelezaSoft** direto pra dentro do AgendIAgora.

Vem de outro sistema? Fale com a gente. Se você já usou de verdade e
gostou do AgendIAgora, avaliamos caso a caso se dá pra trazer seus
dados também — depende do sistema de origem e do tempo disponível, não
é algo automático, mas é pra isso que existe o contato abaixo.
